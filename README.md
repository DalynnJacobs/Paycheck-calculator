# Paycheck Calculator

A Java console application that calculates employee gross pay, deductions, and net pay based on user input.

## Features
- Calculates gross pay based on hours worked and hourly rate
- Applies tax or deduction rules to compute net pay
- Handles multiple employee inputs using loops
- Includes input validation to ensure accurate data entry
- Outputs formatted pay results for each employee

## Technologies Used
- Java
- Loops and conditionals
- Input validation
- Console-based user interaction

## Purpose
This project was built to practice fundamental programming concepts such as decision-making logic, loops, and input validation while simulating a real-world payroll system.

## How to Run
1. Compile the program using a Java compiler:
   javac PaycheckCalculator.java
2. Run the program:
   java PaycheckCalculator
